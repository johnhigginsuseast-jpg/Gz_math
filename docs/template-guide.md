# 后续知识点如何复用本模板

复用八环节学习骨架：情景预测→图形构造→单变量引导实验→规律→自由探索→分步例题→练习→小结。首先独立定义新课的需求、知识边界、观察目标和验收数据，确认后实现。

课程内容集中在site/course.mjs：course记录标题、目标、步骤、情景、三轮实验问题、分步例题；exercises声明稳定题目id、题型、选项、正确索引、针对性反馈和复习点。题目答案和反馈应先手工数学复核，再加入独立测试数据。

v0.2在同一课程中用topics分组位置关系、弦长、最值、动直线和切线；例题/练习通过topic字段归类，新增内容不得写死总数。数学比较符号作为文本插入HTML时需转义，不能将d<r等内容直接当成标签。SVG标签在窄屏需补偿viewBox缩放，不能只看CSS字号。

site/app.mjs负责页面骨架和本课实验的SVG视图；site/math.mjs提供本课直线与圆计算。后续知识点保留视觉、步骤、选择反馈和逐步展开模式，为新数学内容另写最小实验模块及不变量测试，不把直线与圆函数强行通用化。

site/state.mjs负责可恢复的进度、观察和作答。新课需要独立课程id、存储键和版本；不能覆盖本课记录。当前样板刻意只包含一课，尚未建设课程目录、编辑器或发布系统。

同一课扩充内容时保留原题目id，按内容修订号迁移旧记录：保留已答旧题与基础实验，新增内容标为未学，撤销旧版后半课的完成标记。本课v0.1→v0.2迁移已有独立旧结构夹具与浏览器验证。

数学实验要求：先构造后公式；引导阶段每次只改变一个量；图形和数值共用计算结果；记录学生的预测、实际观察及修正。新课至少提供两道分步例题及覆盖本课目标的练习，保留错答重试和复习总结。

每次新增课程都应在浏览器真实走通完整流程、键盘操作、刷新恢复和三宽度布局，再记录候选校验值与验收证据。旧课测试通过不代表新课已经通过。
# v0.3 模块内继续扩课

首页和五个新课的学习骨架位于module-app.mjs，课程数据与独立状态位于module-course.mjs。增加同类课时，提供情景问题、实验参数/目标、知识条目、分步例题及练习答案；在module-app的model中加入与图形共用的计算，并为新增数学写不变量/已知值检查。不要只复制标题或把实验换成静态说明。

旧直线与圆课保留原八环节与geometry-lab-v1；新课在geometry-module-v1下按ID保存。更改既有题目答案/ID时需迁移和重新计算完成状态，不能沿用过期100%。新增模块不在本轮范围。

# v0.4 三模块层级与空间/曲线实验

根入口展示module-course.mjs的modules（三模块同级），module参数选择模块、lesson参数选择唯一课程ID。新增课程按moduleId进入对应模块，不能把整个模块混进某节课的实验标签。旧六课ID和存储键保留。

solid-course/conic-course复用lesson-data中五种数据构造；数学放advanced-math，实验模型放advanced-labs，界面沿用module-app。空间模型提供三维点/线/面，spaceSvg按观察视角作正投影；视角保存在课程view中，不参与真实几何量计算。曲线模型通过同一conicLine计算交点/弦，再绘图和判观察，不能另写只好看的交点。

每个实验需提供独立已知值或几何不变量检查，并在浏览器走通预测、记录与应用。添加实验、题目或步骤会影响原完成条件，须检查恢复逻辑，不把既有100%冒充新增已学。三维透视形状不能当作实际角度与距离。
