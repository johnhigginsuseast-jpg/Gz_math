## 不照抄的四处结论

1. 段230：圆上点到直线的最小距离为max(0,d-r)，相交时为0；|d-r|只在d≥r时与它一致。
2. 段233：F+λl包含λ=0对应原圆。原文“不含圆F本身”与其参数式矛盾，网站按代入结果讲解。
3. 段207：内切条件需要d>0；同心同半径为重合。同心不等圆在包含关系下单列，避免混淆。
4. 段241：圆外点过点直线垂直CP可能相离；只对相交直线讨论弦，最小值0仅能逼近（若纳入切线则可取0）。圆内点情形才可直接套闭区间公式。
