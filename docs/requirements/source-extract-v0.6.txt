P004 第六章 平面向量及其应用
P005 6.1 平面向量的概念
P006 向量的定义：既有大小又有方向的量，如力、位移、速度。向量可以用有向线段表示，记作 a→ 或 AB→。
P007 向量的模：向量的大小（长度），记作 |a→|。
P008 零向量：长度为 0 的向量，方向任意，记作 0→。
P009 单位向量：长度等于 1 个单位的向量；与 a→ 同方向的单位向量为 a→/|a→|。
P010 平行向量（共线向量）：方向相同或相反的非零向量，规定 0→ 与任一向量平行，记作 a→∥b→。
P011 相等向量：长度相等且方向相同的向量；向量只与大小方向有关，与起点位置无关（自由向量）。
P012 相反向量：长度相等、方向相反的向量，a→ 的相反向量记作 −a→。
P013 6.2 平面向量的运算
P014 一、向量的加法
P015 三角形法则：首尾相接，和向量由起点指向终点（AB→ + BC→ = AC→）。
P016 平行四边形法则：共起点 a→、b→，以它们为邻边作平行四边形，对角线为和向量。
P017 运算律：交换律 a→+b→=b→+a→；结合律 (a→+b→)+c→=a→+(b→+c→)。
P018 不等式：||a→|−|b→|| ≤ |a→+b→| ≤ |a→|+|b→|（等号在共线时取得）。
P019 二、向量的减法
P020 a→ − b→ = a→ + (−b→)；AB→ − AC→ = CB→（同起点减，指向被减向量终点）。
P021 三、数乘运算
P022 实数 λ 与向量 a→ 的积 λa→ 仍是向量：|λa→|=|λ||a→|；λ>0 同向，λ<0 反向，λ=0 为零向量。
P023 运算律：λ(μa→)=(λμ)a→；(λ+μ)a→=λa→+μa→；λ(a→+b→)=λa→+λb→。
P024 向量共线定理：a→∥b→(b→≠0→) ⟺ 存在唯一实数 λ，使 a→=λb→。
P025 ★ 高频考法：用向量共线定理证明三点共线（若 AB→=λAC→，则 A、B、C 共线）。
P026 四、平面向量基本定理与坐标表示
P027 基本定理：若 e₁→、e₂→ 是同一平面内两个不共线向量（基底），则该平面内任一向量 a→ 有唯一分解 a→ = λ₁e₁→ + λ₂e₂→。
P028 正交分解：取互相垂直的单位向量 i→、j→ 作基底，a→ = xi→ + yj→，记作 a→=(x, y)。
P029 坐标运算：a→±b→=(x₁±x₂, y₁±y₂)；λa→=(λx, λy)。
P030 向量坐标 = 终点坐标 − 起点坐标：AB→ = (x_B−x_A, y_B−y_A)。
P031 共线坐标判定：a→∥b→ ⟺ x₁y₂ − x₂y₁ = 0（交叉相乘相等，注意与垂直判定的区分！）。
P032 五、数量积（内积）
P033 a→·b→ = |a→||b→|cosθ = x₁x₂ + y₁y₂
P034 θ 为两向量夹角，范围 [0°, 180°]；a→·b→ 的结果是数（数量），不是向量。
P035 几何意义：a→·b→ = |a→|·(b→ 在 a→ 方向上的投影)。
P036 垂直判定：a→⊥b→ ⟺ a→·b→=0 ⟺ x₁x₂ + y₂y₁... 注意：x₁x₂ + y₁y₂ = 0。
P037 模长公式：|a→| = √(x² + y²)；|AB→| = √((x_B−x_A)² + (y_B−y_A)²)（即两点间距离公式）。
P038 夹角公式：cosθ = (a→·b→)/(|a→||b→|) = (x₁x₂+y₁y₂)/(√(x₁²+y₁²)·√(x₂²+y₂²))。
P039 运算律：a→·b→=b→·a→；(λa→)·b→=λ(a→·b→)；(a→+b→)·c→=a→·c→+b→·c→。
P040 重要不等式：|a→·b→| ≤ |a→||b→|。
P041 ★ 易错：① 数量积不满足结合律：(a→·b→)c→ ≠ a→(b→·c→)（前者与 c→ 平行，后者一般不是）；② 求夹角前先看是否有零向量；③ cosθ 的符号由数量积决定，可用于判断角为锐角/钝角/直角。
P042 ★ 高频考法：① 坐标运算求模、求夹角、判断垂直/平行；② "以形助数"：用向量法证明几何关系（垂直、共线）；③ 最值问题借助 |a→±b→|² = |a→|² ± 2a→·b→ + |b→|² 展开。
P043 6.3–6.4 向量应用：解三角形与实际问题
P044 一、余弦定理
P045 a² = b² + c² − 2bc·cosA
P046 cosA = (b² + c² − a²)/(2bc)
P047 适用：已知两边及夹角（SAS）求第三边；已知三边（SSS）求角。
P048 推论判断三角形形状：A 为锐角 ⟺ a² < b² + c²；A 为直角 ⟺ a² = b² + c²；A 为钝角 ⟺ a² > b² + c²。
P049 二、正弦定理
P050 a/sinA = b/sinB = c/sinC = 2R（R 为外接圆半径）
P051 适用：已知两角及一边（AAS/ASA）；已知两边及其中一边的对角（SSA，需注意解的个数）。
P052 SSA 解的个数判断（已知 a, b, A）：① A 为钝角或直角时，a>b 一解，a≤b 无解；② A 为锐角时，a<bsinA 无解，a=bsinA 一解，bsinA<a<b 两解，a≥b 一解。
P053 边角互化：a=2RsinA 等，齐次式中可用 sin 替换边。
P054 三、三角形面积公式
P055 S = (1/2)ab·sinC = (1/2)bc·sinA = (1/2)ac·sinB
P056 S = abc/(4R) = r·s（s 为半周长，r 为内切圆半径）
P057 四、测量应用（实际问题）
P058 仰角与俯角：视线与水平线的夹角（向上为仰角，向下为俯角）。
P059 方位角：从正北方向顺时针旋转到目标方向线的角（0°~360°）。
P060 坡角与坡度：坡面与水平面的夹角为坡角 α；坡度 i = h/l = tanα。
P061 不可到达的两点间距离、底部不可达的物体高度等问题：构造三角形用正、余弦定理求解。
P062 ★ 高频考法：解三角形大题常结合三角恒等变换（必修一知识）；判断三角形形状（角化边或边化角）；周长、面积最值（结合基本不等式或二次函数）。
P063 第七章 复数
P064 7.1 复数的概念
P065 定义：形如 z = a + bi（a, b ∈ R）的数，a 为实部，b 为虚部，i 为虚数单位，规定 i² = −1。
P066 分类：b=0 时为实数；b≠0 时为虚数；a=0 且 b≠0 时为纯虚数。
P067 复数相等：a+bi = c+di ⟺ a=c 且 b=d（实部、虚部分别相等）。
P068 共轭复数：z = a+bi 的共轭复数 z̄ = a−bi；z·z̄ = |z|² = a² + b²。
P069 复平面：实部为横坐标、虚部为纵坐标；实轴上的点表示实数，虚轴（除原点）上的点表示纯虚数。
P070 复数的模：|z| = √(a² + b²)，几何意义是复平面上对应点到原点的距离。
P071 复数无大小关系（除非都是实数）。
P072 7.2 复数的四则运算
P073 加减：(a+bi) ± (c+di) = (a±c) + (b±d)i
P074 乘法：(a+bi)(c+di) = (ac−bd) + (ad+bc)i
P075 除法：(a+bi)/(c+di) = [(ac+bd) + (bc−ad)i]/(c²+d²)（分母实数化：乘共轭）
P076 运算律：加法、乘法均满足交换律、结合律与分配律。
P077 常用结论：i⁴ⁿ=1，i⁴ⁿ⁺¹=i，i⁴ⁿ⁺²=−1，i⁴ⁿ⁺³=−i；(1±i)² = ±2i；(1+i)/(1−i) = i。
P078 z̄̄ = z；z̄ = z ⟺ z 为实数；z̄ = −z ⟺ z 为纯虚数（z≠0）。
P079 ★ 高频考法：① 求共轭复数、模、实部虚部（送分题，注意虚部是实数 b 而不是 bi）；② 复平面内对应点所在象限；③ i 的周期性求 i 的高次幂。
P080 7.3 复数的三角表示（选学/了解）
P081 三角形式：z = r(cosθ + i·sinθ)，r 为模，θ 为辐角；乘除时模相乘除、辐角相加减（棣莫弗定理背景）。
P082 第八章 立体几何初步
P083 8.1 基本立体图形
P084 多面体：棱柱（两个面互相平行且全等，侧棱平行且相等——直棱柱侧棱垂直底面，正棱柱底面是正多边形）、棱锥（一个面是多边形，其余是共顶点的三角形）、棱台（用平行于棱锥底面的平面截棱锥得到）。
P085 旋转体：圆柱（矩形绕一边旋转）、圆锥（直角三角形绕一直角边旋转）、圆台、球。
P086 球的截面：截面是圆，球心到截面圆心的连线垂直于截面；r² = R² − d²（r 截面圆半径，R 球半径，d 距离）。
P087 简单组合体：由柱、锥、台、球等基本几何体组合或挖去而成。
P088 8.2 立体图形的直观图（斜二测画法）
P089 规则：① 原图中互相垂直的 x、y 轴画成 x′、y′ 轴，夹角 45°（或 135°）；② 平行于 x 轴的线段长度不变，平行于 y 轴的线段长度减半；③ 平行关系保持不变。
P090 面积关系：S_直观图 = (√2/4)·S_原图；S_原图 = 2√2·S_直观图。
P091 ★ 易错：斜二测中平行于 y 轴的线段"减半"，判断直观图与原图关系时容易忽略面积比。
P092 8.3 简单几何体的表面积与体积
P093 柱体体积 V = Sh；锥体体积 V = (1/3)Sh；台体体积 V = (1/3)(S′+S+√(S′S))h
P094 球的体积 V = (4/3)πR³；球的表面积 S = 4πR²
P095 圆柱侧面积 S_侧 = 2πrl；圆锥侧面积 S_侧 = πrl（l 为母线）；圆台侧面积 S_侧 = π(r+R)l
P096 柱体展开图：矩形（一边为底面周长，一边为高）。
P097 圆锥展开图：扇形，扇形半径 = 母线 l，弧长 = 底面周长 2πr，故侧面展开扇形圆心角 = (r/l)·360°。
P098 等底等高时，锥体体积是柱体的 1/3（"祖暅原理"相关考点）。
P099 ★ 高频考法：组合体表面积注意重叠面不计；体积问题常用"等体积法"转换顶点（如求点到平面距离）；球与柱、锥的切接问题画出轴截面转化为平面问题。
P100 8.4 空间点、直线、平面之间的位置关系
P101 平面的基本性质（三个公理）：① 不共线三点确定一个平面；② 直线上两点在平面内，则直线在平面内；③ 两平面有一个公共点，则它们有且只有一条过该点的公共直线。
P102 推论：一条直线和直线外一点确定一个平面；两条相交直线确定一个平面；两条平行直线确定一个平面。
P103 直线与直线：相交、平行、异面（不同在任何一个平面内，无公共点，既不平行也不相交）。
P104 直线与平面：在平面内、相交（1个公共点）、平行（无公共点）。
P105 平面与平面：平行（无公共点）、相交（一条公共直线）。
P106 等角定理：空间中如果两个角的两边分别对应平行，那么这两个角相等或互补。
P107 异面直线所成角：平移其中一条使之相交，所成锐角或直角，范围 (0°, 90°]。
P108 ★ 判断异面直线常用"反证法"：假设共面，则与已知条件矛盾。
P109 8.5 空间直线、平面的平行
P110 线面平行判定：平面外一条直线与此平面内的一条直线平行，则该直线与此平面平行（a⊄α，b⊂α，a∥b ⟹ a∥α）
P111 线面平行性质：一条直线与一个平面平行，则过这条直线的任一平面与此平面的交线与该直线平行（a∥α，a⊂β，α∩β=b ⟹ a∥b）
P112 面面平行判定：一个平面内的两条相交直线与另一个平面平行，则两平面平行
P113 面面平行性质：两平面平行，则一个平面内的直线必平行于另一个平面；第三平面与它们相交则交线平行
P114 重要结论：夹在两个平行平面间的平行线段相等；经过平面外一点有且只有一个平面与已知平面平行。
P115 证明平行关系的转化链：线线平行 ⟹ 线面平行 ⟹ 面面平行。
P116 8.6 空间直线、平面的垂直
P117 一、线线垂直与线面垂直
P118 线面垂直判定：一条直线与一个平面内的两条相交直线都垂直，则该直线与此平面垂直
P119 线面垂直性质：垂直于同一个平面的两条直线平行。
P120 点到平面距离、直线到平面距离（线面平行时）的定义。
P121 直线与平面所成角：直线与其在平面内的射影所成的角，范围 [0°, 90°]。
P122 二、二面角与面面垂直
P123 二面角：从一条直线出发的两个半平面所成的图形；二面角的平面角：棱上一点在两个半平面内分别作棱的垂线，两垂线的夹角，范围 [0°, 180°]。
P124 面面垂直判定：一个平面过另一个平面的垂线，则两平面垂直（找线面垂直是关键）。
P125 面面垂直性质：两个平面垂直，则一个平面内垂直于交线的直线与另一个平面垂直。
P126 求线面角：sinθ = |cos<a→, n→>|（a→ 直线方向向量，n→ 平面法向量）——空间向量法（选学拓展）
P127 ★ 高频考法：垂直关系的证明关键是"线线垂直 → 线面垂直 → 面面垂直"的转化；证明线线垂直常先证一线垂直于另一线所在平面（如直径所对圆周角、菱形对角线、等腰三角形三线合一、勾股定理逆定理等）。
P128 三、空间向量及其应用（选学）
P129 空间向量坐标运算与平面向量类似（多一个 z 分量）；用方向向量与法向量求线面角、二面角（注意二面角与法向量夹角的关系需判断锐钝）。
P130 距离公式：点到平面距离 d = |AP→·n→|/|n→|。
P131 第九章 统计
P132 9.1 随机抽样
P133 统计基本概念：总体、个体、样本、样本容量；样本估计总体的思想。
P134 简单随机抽样：抽签法、随机数法；特点：逐个抽取、不放回、等可能性；适用于总体个数较少。
P135 分层随机抽样：总体由差异明显的几部分组成时，按各层比例抽取：每层样本量 = 该层个体数 × (样本容量/总体容量)；各层可采用简单随机抽样；分层抽样仍是等可能抽样。
P136 平均数与方差的加权形式：分层抽样中样本均值 x̄ = Σ(W_i·x̄_i)，W_i 为层权；样本方差 s² = ΣW_i[s_i² + (x̄_i − x̄)²]。
P137 ★ 高频考法：① 根据分层比例求某层应抽取人数（按比例分配）；② 由样本数据估计总体数量。
P138 9.2 用样本估计总体
P139 一、集中趋势
P140 平均数 x̄ = (x₁+x₂+…+xₙ)/n；加权平均数 x̄ = Σ(x_i·f_i)/Σf_i
P141 中位数：从小到大排列后位于中间位置的数（奇数个取中间，偶数个取中间两数平均）。
P142 众数：出现次数最多的数（可能不止一个）。
P143 平均数受极端值影响大；中位数、众数较稳健。
P144 二、离散程度
P145 方差 s² = (1/n)Σ(x_i − x̄)²；标准差 s = √s²
P146 方差计算技巧：s² = (1/n)Σx_i² − x̄²
P147 方差/标准差越小，数据越稳定、波动越小。
P148 新数据 ax_i + b 的均值 a·x̄+b，方差 a²s²（注意 b 不影响方差）。
P149 三、频率分布表与频率分布直方图
P150 作图步骤：求极差 → 定组距与组数 → 分组 → 列频率分布表 → 画直方图。
P151 直方图纵轴为"频率/组距"，小矩形面积 = 频率，所有矩形面积之和 = 1。
P152 估计：众数 ≈ 最高矩形底边中点；中位数：左右面积各 0.5 处的横坐标；平均数 ≈ Σ(各矩形底边中点 × 对应频率)。
P153 总体百分位数：一组数据的第 p 百分位数：计算 i = n×p%，若 i 不是整数取第 [i]+1 项，若 i 是整数取第 i 与第 i+1 项的平均数。
P154 ★ 高频考法：由直方图求频率（面积）、频数（频率×总数）、中位数/平均数估计；频率分布直方图中"面积和为1"是列方程求未知组距/纵坐标的突破口。
P155 第十章 概率
P156 10.1 随机事件与概率
P157 事件分类：必然事件、不可能事件（统称确定事件）、随机事件。
P158 事件的关系：包含（B⊇A）、相等、并事件（和事件 A∪B，至少一个发生）、交事件（积事件 A∩B，同时发生）、互斥事件（不能同时发生，A∩B=∅）、对立事件（互斥且必有一个发生，A∪B=Ω）。
P159 概率的基本性质：0 ≤ P(A) ≤ 1；P(必然事件)=1，P(不可能事件)=0；互斥时 P(A∪B)=P(A)+P(B)；对立时 P(A)=1−P(Ā)。
P160 古典概型：① 有限性（样本点有限）；② 等可能性。P(A) = A 包含的样本点数 / 样本点总数。
P161 求古典概型概率：列举法、列表法、画树状图法（注意"有序"与"无序"的区别，如掷两枚骰子、取球问题）。
P162 ★ 易错：① 互斥不一定对立，对立一定互斥；② "有放回"与"无放回"抽样样本点数不同；③ 计算时保证样本点等可能（如两个相同球的情况易错算）。
P163 10.2 事件的相互独立性
P164 P(AB) = P(A)·P(B)（A、B 相互独立）
P165 独立：一个事件的发生不影响另一个事件发生的概率。
P166 必然事件、不可能事件与任何事件独立；若 A、B 独立，则 Ā 与 B、A 与 B̄、Ā 与 B̄ 也相互独立。
P167 与互斥的区别：互斥强调"不能同时发生"（针对同一试验的事件关系），独立强调"互不影响"（强调概率计算）。
P168 10.3 频率与概率
P169 频率的稳定性：大量重复试验中频率稳定在概率附近，用频率估计概率（随机模拟/蒙特卡洛方法）。
P170 用计算器或计算机产生随机数模拟试验，估计概率。
P171 ★ 高频考法：与统计结合的解答题（分层抽样 + 古典概型/独立事件求概率）；比赛、闯关、"至少""至多"问题常用对立事件转化。
P172 附：高频考点清单与备考建议
P173 一、按题型分布的高频考点
P174 小题高频：复数运算与模、平面向量数量积（垂直/夹角/模）、抽样方法计算、直方图读图、古典概型与独立事件概率。
P175 大题高频：① 解三角形（正余弦定理+面积公式+三角恒等变换）；② 立体几何（线面平行/垂直证明+体积/表面积计算，或向量法求角）；③ 统计概率综合（频率分布直方图+分层抽样+概率计算）。
P176 易错清单：向量夹角范围与投影方向、SSA 多解讨论、异面直线所成角范围、斜二测面积比、直方图纵轴含义（频率/组距而非频率）、百分位数取数规则、"至少有一个"用对立事件。
P177 二、核心公式速记卡
P178 数量积：a→·b→ = |a→||b→|cosθ = x₁x₂+y₁y₂；垂直 ⟺ x₁x₂+y₁y₂=0；平行 ⟺ x₁y₂−x₂y₁=0
P179 正弦定理 a/sinA = 2R；余弦定理 a² = b²+c²−2bc·cosA；面积 S = (1/2)ab·sinC
P180 z·z̄ = |z|² = a²+b²；i²=−1，i 的幂周期为 4
P181 V_柱=Sh；V_锥=(1/3)Sh；V_球=(4/3)πR³；S_球=4πR²
P182 s² = (1/n)Σ(x_i−x̄)² = (1/n)Σx_i² − x̄²
P183 古典概型 P(A)=样本点数之比；独立事件 P(AB)=P(A)P(B)；对立事件 P(A)=1−P(Ā)
