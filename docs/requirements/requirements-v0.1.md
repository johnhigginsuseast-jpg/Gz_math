## 目标与用户

高中生独立完成一节基础探究课，理解直线与圆相交、相切、相离的判据，并能用距离公式解决基础问题。原始《高中数学知识点详解.docx》保留；仅采用经核对的相关数学内容。

## 范围与布局

本地静态网站，使用 Windows 的现代浏览器。明亮浅色实验室风格，桌面侧边步骤导航、主内容与图形并排，窄屏上下排列。八个环节：情景、构造、引导实验、归纳、自由探索、例题、练习、小结。未学步骤按进程解锁，已学步骤可回看。控件具有文本标签、键盘支持和可见焦点，反馈不只依靠颜色。

## 功能需求

| 编号 | 必需行为 | 边界和反馈 |
|---|---|---|
| FR-001 | 道路与圆形公园情景，学生预测公共点变化 | 明确研究完整直线和圆周，预测前不揭示答案 |
| FR-002 | 分步构造圆心、半径、圆周、直线，支持播放、暂停、重播 | 完成后显示圆与直线表达式，再允许进入实验 |
| FR-003 | 固定 r=3、y=t，t∈[-5,5]、步长0.1，按 t=2、3、4 完成预测、操作、观察、记录 | 每轮只改变 t；未预测不能操作，未到目标或观察错误不能记录；提供准确预设按钮 |
| FR-004 | 实验后展示 d 与 r 判据和一般点线距离公式，包含必要前置知识 | A²+B²≠0、r>0；理解问题回答后进入自由探索 |
| FR-005 | 自由改变半径1～4、有向平移量-5～5、旋转角0°～180° | 0°/180°不宣称同一直线；图形等比例；显示圆心、垂足、交点、距离、关系；可恢复初始状态 |
| FR-006 | 两道例题按圆心半径、距离、比较或方程、结论逐步展开 | x²+y²=9 与 x+y=3；(x-1)²+(y-2)²=4 与 x+y+c=0，相切 c=-3±2√2 |
| FR-007 | 六道单选或多选练习，覆盖三种关系、距离、相切两取值、旋转不变性 | 提交后显示针对性解释，错误可重试；重复提交不重复累计完成数 |
| FR-008 | 小结、正确完成情况、需复习知识点，允许回看和重做 | 不把错误回答计算为正确完成 |
| FR-009 | 当前浏览器保存步骤、实验记录、作答，刷新恢复，提供清空重学 | 存储不可用或损坏时提示，仍可学习；明确无跨设备同步 |
| FR-010 | 课程数据与页面、实验模块分离，附后续课例复用说明 | 不建立课程编辑后台或万能实验引擎 |
