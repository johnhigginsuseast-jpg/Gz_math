P001 高中数学选择性必修第二册知识点与考点全整理
P002 （人教A版·适用高考复习）
P003 本册内容概览：
P004 选择性必修第二册共两章：第四章《数列》、第五章《一元函数的导数及其应用》。数列是高考的必考内容，常以等差、等比数列的基本量运算和小题形式出现，也常与函数、不等式结合命制大题；导数是高考压轴题的核心工具，贯穿函数单调性、极值、最值、恒成立与不等式证明等各类问题。
P005 第四章  数列
P006 4.1  数列的概念
P007 1. 数列的定义：按照确定的顺序排列的一列数，记作 {aₙ}。数列是定义域为正整数集 N*（或其有限子集）的函数 aₙ = f(n)，即数列是特殊的函数。
P008 2. 数列的分类：
P009 （1）按项数：有穷数列、无穷数列；
P010 （2）按单调性：递增数列、递减数列、常数列、摆动数列。
P011 3. 通项公式：如果数列 {aₙ} 的第 n 项 aₙ 与序号 n 之间的关系可以用一个公式表示，则此公式称为通项公式。注意：并非所有数列都有通项公式，且通项公式不唯一。
P012 4. 递推公式：已知首项（或前几项），且任一项 aₙ 与它的前一项 aₙ₋₁（或前几项）间的关系可以用公式表示，如 aₙ = aₙ₋₁ + f(n)。
P013 5. 前 n 项和：Sₙ = a₁ + a₂ + … + aₙ；aₙ 与 Sₙ 的关系（重要考点）：
P014 aₙ = S₁ (n=1)；aₙ = Sₙ − Sₙ₋₁ (n≥2)
P015 【考点】由 Sₙ 求 aₙ 必须分段讨论并检验 n=1 的情形；已知 Sₙ 与 aₙ 混合关系时，常用"退位相减法"（写出 Sₙ₋₁ 作差）。
P016 4.2  等差数列
P017 1. 定义：一般地，如果一个数列从第 2 项起，每一项与它的前一项的差等于同一个常数，这个数列叫等差数列，常数 d 叫公差，即 aₙ − aₙ₋₁ = d (n≥2)。
P018 2. 通项公式：
P019 aₙ = a₁ + (n−1)d；推广：aₙ = aₘ + (n−m)d
P020 3. 等差中项：若 a, A, b 成等差数列，则 2A = a + b，A 称为 a 与 b 的等差中项。
P021 4. 前 n 项和公式：
P022 Sₙ = n(a₁ + aₙ)/2 = na₁ + n(n−1)d/2
P023 5. 常用性质（高频考点）：
P024 （1）若 m+n = p+q，则 aₘ + aₙ = aₚ + a_q；特别地，m+n = 2p 时 aₘ + aₙ = 2a_p；
P025 （2）下标成等差的项仍成等差数列，公差为原公差的倍数；
P026 （3）Sₙ, S₂ₙ−Sₙ, S₃ₙ−S₂ₙ, … 仍成等差数列，公差为 n²d；
P027 （4）若 {aₙ}、{bₙ} 均为等差数列，则 {aₙ±bₙ}、{kaₙ} 也是等差数列；
P028 （5）Sₙ 关于 n 是缺常数项的二次函数：Sₙ = (d/2)n² + (a₁−d/2)n；d>0 时 Sₙ 有最小值，d<0 时 Sₙ 有最大值（也可用"邻项变号法"求最值）；
P029 （6）项数为 2n 时：S偶 − S奇 = nd，S偶/S奇 = aₙ₊₁/aₙ；项数为 2n−1 时：S奇 − S偶 = aₙ（中间项），S奇/S偶 = n/(n−1)。
P030 【考点】等差数列基本量运算（"知三求二"：a₁, d, n, aₙ, Sₙ 五个量知三求二）是送分题；性质速解、Sₙ 最值是常考题型。
P031 4.3  等比数列
P032 1. 定义：从第 2 项起，每一项与它的前一项的比等于同一个常数，这个数列叫等比数列，常数 q (q≠0) 叫公比，即 aₙ/aₙ₋₁ = q (n≥2)。
P033 2. 通项公式：
P034 aₙ = a₁·qⁿ⁻¹；推广：aₙ = aₘ·qⁿ⁻ᵐ
P035 3. 等比中项：若 a, G, b 成等比数列，则 G² = ab，G = ±√(ab)（a, b 同号时才有实等比中项）。
P036 4. 前 n 项和公式：
P037 Sₙ = na₁ (q=1)；Sₙ = a₁(1−qⁿ)/(1−q) = (a₁−aₙq)/(1−q) (q≠1)
P038 【易错】用等比求和公式前必须先讨论 q 是否等于 1！
P039 5. 常用性质（高频考点）：
P040 （1）若 m+n = p+q，则 aₘ·aₙ = a_p·a_q；特别地 m+n = 2p 时 aₘ·aₙ = a_p²；
P041 （2）每隔相同项取出的项仍成等比数列；
P042 （3）Sₙ, S₂ₙ−Sₙ, S₃ₙ−S₂ₙ, … 仍成等比数列（要求分母不为 0，即 q≠−1 或 n 为奇数）；
P043 （4）若 {aₙ}、{bₙ} 均为等比数列，则 {aₙbₙ}、{aₙ/bₙ}、{aₙᵏ} 也是等比数列；
P044 （5）当 q>1 且 a₁>0（或 0<q<1 且 a₁<0）时数列递增；q<0 时数列摆动；
P045 （6）单调递增的等比数列前 n 项和 Sₙ 不一定有最值（当各项为正时 Sₙ 递增无最大值）。
P046 【考点】等比中项的正负判断（结合数列各项符号）、Sₙ 公式中 q=1 的讨论是易错点与常考点。
P047 4.4  数学归纳法
P048 1. 适用对象：证明与正整数 n 有关的命题。
P049 2. 两个步骤缺一不可：
P050 （1）（归纳奠基）证明 n = n₀（n₀ ∈ N*）时命题成立；
P051 （2）（归纳递推）假设 n = k (k ≥ n₀) 时命题成立，证明 n = k+1 时命题也成立。
P052 由（1）（2）可知命题对从 n₀ 开始的所有正整数 n 都成立。
P053 【考点】新高考中数学归纳法常作为证明数列不等式、猜想—证明类问题的工具；重点考查"由 n=k 到 n=k+1 时式子的变化"，即归纳假设的代入与目标式的配凑。
P054 第五章  一元函数的导数及其应用
P055 5.1  导数的概念及其意义
P056 1. 平均变化率：函数 y = f(x) 从 x₁ 到 x₂ 的平均变化率为
P057 Δy/Δx = [f(x₂) − f(x₁)] / (x₂ − x₁)
P058 2. 瞬时变化率与导数：设函数 y = f(x) 在 x₀ 附近有定义，当 Δx→0 时，平均变化率的极限叫做 f(x) 在 x = x₀ 处的导数（瞬时变化率），记作 f′(x₀) 或 y′|ₓ₌ₓ₀：
P059 f′(x₀) = lim(Δx→0) [f(x₀+Δx) − f(x₀)] / Δx
P060 3. 导数的几何意义：函数 y = f(x) 在点 x₀ 处的导数 f′(x₀) 就是曲线 y = f(x) 在点 P(x₀, f(x₀)) 处切线的斜率，即 k = f′(x₀)。相应地，切线方程为：
P061 y − f(x₀) = f′(x₀)(x − x₀)
P062 4. 导函数：当 x 变化时，f′(x) 就是 x 的函数，称 f′(x) 为 f(x) 的导函数。
P063 【考点】已知切点求切线（直接代入）；未知切点求切线（设切点列方程组）；公切线问题；两曲线交点处切线问题。注意区分"在点 P 处"与"过点 P"的切线。
P064 5.2  导数的运算
P065 1. 基本初等函数的导数公式：
P066 C′ = 0（C 为常数）；(xᵅ)′ = αxᵅ⁻¹（α ∈ Q，且 α≠0）；
P067 (sin x)′ = cos x；(cos x)′ = −sin x；
P068 (aˣ)′ = aˣ·ln a（a>0 且 a≠1）；(eˣ)′ = eˣ；
P069 (logₐx)′ = 1/(x·ln a)（a>0 且 a≠1）；(ln x)′ = 1/x。
P070 2. 导数的四则运算法则：
P071 [f(x) ± g(x)]′ = f′(x) ± g′(x)；
P072 [f(x)·g(x)]′ = f′(x)g(x) + f(x)g′(x)；
P073 [f(x)/g(x)]′ = [f′(x)g(x) − f(x)g′(x)] / [g(x)]² (g(x)≠0)。
P074 3. 简单复合函数的求导（链式法则）：
P075 对于由 y = f(u) 和 u = g(x) 复合而成的函数 y = f(g(x))，它的导数为
P076 y′ₓ = y′ᵤ · u′ₓ
P077 例如：[e^(2x)]′ = 2e^(2x)；[ln(2x+1)]′ = 2/(2x+1)；[sin(3x)]′ = 3cos(3x)。
P078 【考点】复合函数求导是新高考明确要求的考点，常与 eˣ、ln x、三角函数复合形式结合，是后续一切导数应用的基础，务必熟练。
P079 5.3  导数在研究函数中的应用
P080 1. 函数的单调性与导数（核心考点）：
P081 （1）在某个区间 (a, b) 内，如果 f′(x) > 0，那么函数 y = f(x) 在这个区间内单调递增；如果 f′(x) < 0，那么单调递减。
P082 （2）求可导函数单调区间的一般步骤：① 求定义域；② 求导数 f′(x)；③ 解不等式 f′(x) > 0 得递增区间，f′(x) < 0 得递减区间（注意区间不能跨过定义域断点）。
P083 （3）已知单调性求参数范围：转化为 f′(x) ≥ 0（或 ≤0）在区间上恒成立，注意检验等号成立时是否使函数成为常函数。
P084 2. 函数的极值：
P085 （1）定义：若函数 f(x) 在点 x₀ 附近的函数值都比 f(x₀) 小（或大），则 f(x₀) 是极大值（或极小值），x₀ 为极值点。极值点不是点，是横坐标的值。
P086 （2）求极值步骤：求定义域 → 求 f′(x) → 求 f′(x)=0 的根 → 列表判断导数符号变化（左正右负为极大值，左负右正为极小值）。
P087 （3）注意：f′(x₀)=0 是 x₀ 为极值点的必要不充分条件（如 f(x)=x³ 在 x=0 处）；必须检验两侧符号变化。
P088 3. 函数的最大（小）值：
P089 （1）闭区间 [a, b] 上的连续函数必有最大值和最小值；
P090 （2）求法：求出区间内所有极值与端点值 f(a)、f(b)，比较大小即得最值；
P091 （3）开区间或无穷区间上的最值需结合单调性与图象分析；实际应用问题中注意定义域的实际意义。
P092 5.4  导数的综合应用（高考压轴高频考点）
P093 1. 恒成立与存在性问题——分离参数法：
P094 形如 f(x) ≥ a 对 x∈D 恒成立，等价于 a ≤ f(x)min；f(x) ≥ g(a) 可考虑分离参数，转化为求不含参数函数的最值。注意区分任意（∀）与存在（∃）：∀ 对应最值，∃ 对应最值的相反方向。
P095 2. 零点问题：
P096 利用导数研究函数的单调性、极值，结合零点存在定理判断零点个数或求参数范围（"数形结合"思想）。
P097 3. 不等式证明：
P098 （1）作差构造函数：欲证 f(x) > g(x)，令 h(x)=f(x)−g(x)，证 h(x)min > 0；
P099 （2）利用常见放缩不等式：eˣ ≥ x+1；ln x ≤ x−1；sin x < x < tan x（0<x<π/2）等；
P100 （3）分析法找矛盾区间，双变量问题常用换元转化为单变量。
P101 4. 双变量与极值点偏移：
P102 已知 f(x₁)=f(x₂)=m，求证 x₁+x₂>2x₀ 之类问题，常用构造对称函数或对数均值不等式 (a−b)/(ln a−ln b) < (a+b)/2 处理。
P103 5. 导数与数列交汇：
P104 利用 ln x ≤ x−1、1/(n+1) < ln(1+1/n) 等不等式放缩证明数列不等式。
P105 高考考点总结与复习建议
P106 1. 数列常考题型：
P107 （1）等差、等比数列基本量计算（选择、填空题高频，难度较低）；
P108 （2）数列单调性、周期性及递推关系求通项（累加法、累乘法、构造法、由 Sₙ 求 aₙ）；
P109 （3）数列求和：公式法、分组求和、裂项相消、错位相减（等差×等比型必考方法）、倒序相加；
P110 （4）数列与函数、不等式综合，数学归纳法证明。
P111 2. 导数常考题型：
P112 （1）切线问题（求切线方程、已知切线求参数）；
P113 （2）单调性讨论（含参分类讨论是重点难点）；
P114 （3）极值、最值问题；
P115 （4）恒成立与零点问题（分离参数、分类讨论、数形结合）；
P116 （5）不等式证明与极值点偏移（压轴题）。
P117 3. 复习建议：
P118 （1）数列部分先确保等差等比基本公式与性质滚瓜烂熟，再突破递推求通项与求和的四大方法；
P119 （2）导数部分把"求导—列符号表—写单调区间"的流程规范化，含参讨论时找准分类标准（通常是导函数零点的大小与是否在定义域内）；
P120 （3）整理错题时按"切线、单调性、恒成立、零点、不等式证明"五类归档，总结每类的入手方法。
