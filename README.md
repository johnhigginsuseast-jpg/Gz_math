# 几何实验室 · 直线与圆样板课

本地运行的高中数学自主探究课 v0.1。完成情景预测、图形构造、三轮引导实验、规律归纳、自由探索、两道分步例题、六道练习和学习小结。

## 打开网站

需要 Node.js 24（当前已验证版本见测试记录），不需要安装 npm 依赖。

Windows 双击 `启动几何实验室.cmd`，或在本目录终端运行：

```powershell
npm.cmd start
```

浏览器打开 http://127.0.0.1:4175/ ，保持终端窗口运行。Ctrl+C 停止。若端口被占用，先停止旧服务，或在 PowerShell 中执行 `$env:PORT=4176; npm.cmd start` 并使用新端口。浏览器记录按地址和端口隔离。

## 学习与数据

- 先选择猜想，再构造图形和做实验。实验可以拖动滑块、用方向键、输入数字，也可点击准确目标位置。
- 圆心到直线的距离是垂直距离；相切时只有一个公共点。自由探索中的旋转角不是教材中限定范围的倾斜角。
- 例题逐步展开。六道练习提交后给出解释，允许修改、重试；多选必须选全。
- 学习状态仅存当前浏览器。清除浏览器数据后会丢失；侧栏/窄屏顶部重置按钮会先询问确认。
- 网站不需要互联网，不发送学习数据。存储失败时会显示提示，仍可在本次会话继续。

## 检查与后续开发

```powershell
npm.cmd test
npm.cmd run check
```

页面位于 `site/`，课程内容在 `site/course.mjs`，数学计算在 `site/math.mjs`，进度与答题状态在 `site/state.mjs`。服务只公开 `site/` 内资源，原始DOCX和项目资料不会通过网站访问。

模板扩展见 `docs/template-guide.md`；需求、验收、测试和交付证据见 `docs/`。当前没有其他课程和在线部署。
